# Telecom Customer Churn Data Analysis
Analysis of a telecom company churn data and business recommendations based on findings.

## Overview
SQL-based product analytics project analyzing customer churn patterns 
in a telecom dataset of 667 customers.

## Key Findings
- Customers with **international plan** churn 3x more (35.8% vs 12.4%)
- Customers with **4+ customer service calls** have 36-80% churn rate
- Customers with **voice mail plan** churn 2x less (7% vs 16%)
- **High usage customers** churn 6x more than medium usage customers

## Tools Used
- Python (pandas, matplotlib)
- SQL (SQLite)
- Jupyter Notebook

## Dataset
Orange Telecom Churn Dataset — 667 customers, 20 features
Source (Kaggle): https://www.kaggle.com/datasets/mnassrib/telecom-churn-datasets
